## Risks and unknowns

- Platform dependency coupling: Historical SiteCrawl reference files under `_reference/sitecrawl/` depended on 1Scout platform packages (`core/*`). Active standalone packages (`internal/sitecrawl`, `internal/platform/standalone`, `cmd/sitecrawl-dev`, `go/deps/*`) are completely decoupled, with all required platform dependencies replaced with pure-Go standalone equivalents.
- Risk of premature audit implementation: Attempting to implement `AR-*` rules before standalone crawler parity is reached risks compounding extraction bugs with domain logic defects.
- Risk of divergent refactoring: Over-engineering the crawler package structure during extraction could make future reintegration into 1Scout prohibitively expensive.

## Decisions

- Baseline preservation: Tag `sitecrawl-pre-audit-v1` is immutable and marks the reference state (`82c610d433203374473e1ea76edf4e6c165a3161`) before any standalone migration edits.
- Core freeze preservation: Tag `sitecrawl-standalone-core-v1` is immutable and marks the standalone core freeze (`50760ed89f58b4e3abc68614363536c05516e07a`). Post-freeze documentation updates do not alter frozen code or tag pointers.
- Phased execution: Standalone extraction and buildability precede Audit V1 domain implementation.
- Checkpoint sequencing: Checkpoints A1, A2, A3/A4, A5, and A6 (A6.1, A6.2, A6.3) are COMPLETED. Standalone core is frozen at tag `sitecrawl-standalone-core-v1` (commit `50760ed`). Next milestone is Audit V1 (Evidence Adapter and rule execution).
- Package consolidation strategy: Prefer consolidating Go files into a unified `internal/sitecrawl/` package during standalone extraction to preserve package-private access rather than fracturing into multiple subpackages prematurely.
- Evidence adapter pattern: The boundary between SiteCrawl acquisition and the Audit V1 engine will be an Evidence Adapter converting crawl observations into normalized evidence snapshots, preserving crawler stability.
- Domain authority: All audit logic and rule definitions are governed exclusively by `/knowledge`.
